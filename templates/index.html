CTF Crypto Toolkit

Local-only encoders, decoders, hashes, classical ciphers, and AES/DES helpers.

Kali command reference

echo -n 'text' | base64
printf 'text' | xxd -p
printf 'hex' | xxd -r -p
echo -n 'text' | sha256sum
printf 'text' | md5sum
openssl enc -aes-256-cbc -K KEY_HEX -iv IV_HEX -in input -out output

This application never executes shell commands, accepts uploads, or makes outbound requests.
